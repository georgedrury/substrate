## Props

| Prop       | Type                          | Default | Description                              |
| ---------- | ----------------------------- | ------- | ---------------------------------------- |
| `colours`  | `string[]`                    | —       | Array of hex colour strings              |
| `value`    | `string`                      | —       | Currently selected colour                |
| `onSelect` | `(colour: string) => void`    | —       | Called when a swatch is clicked           |
| `columns`  | `number`                      | `8`     | Grid column count                        |

## Presets

Two built-in palettes are exported for convenience:

```ts
import { MATERIAL_COLOURS, TAILWIND_COLOURS } from "@/components/substrate/swatch-palette"
```
