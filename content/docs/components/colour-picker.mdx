## Components

| Component             | Description                                                            |
| --------------------- | ---------------------------------------------------------------------- |
| `ColourPicker`        | Popover wrapper — renders swatch trigger and picker content in a panel |
| `ColourPickerContent` | Saturation/hue picker with hex input and preview swatch                |
| `ColourSwatch`        | Colour preview button sized `sm` (20px) or `md` (28px)                 |
| `ColourInput`         | Hex colour text input wrapping `HexColorInput` from react-colorful     |

## Props

### ColourPicker

| Prop       | Type                       | Default | Description                |
| ---------- | -------------------------- | ------- | -------------------------- |
| `value`    | `string`                   | —       | Current hex colour value   |
| `onChange` | `(colour: string) => void` | —       | Called when colour changes |
| `children` | `React.ReactNode`          | Swatch  | Custom trigger element     |

### ColourPickerContent

| Prop       | Type                       | Default | Description                |
| ---------- | -------------------------- | ------- | -------------------------- |
| `value`    | `string`                   | —       | Current hex colour value   |
| `onChange` | `(colour: string) => void` | —       | Called when colour changes |

### ColourSwatch

| Prop     | Type           | Default | Description           |
| -------- | -------------- | ------- | --------------------- |
| `colour` | `string`       | —       | Hex colour to display |
| `size`   | `"sm" \| "md"` | `"md"`  | Swatch size           |

### ColourInput

| Prop       | Type                       | Default | Description                |
| ---------- | -------------------------- | ------- | -------------------------- |
| `value`    | `string`                   | —       | Current hex colour value   |
| `onChange` | `(colour: string) => void` | —       | Called when colour changes |
