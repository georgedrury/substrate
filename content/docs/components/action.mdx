## Anatomy

```tsx
import { Action, ActionLabel, ActionControls } from "@/components/substrate/action"

<Action>
  <ActionLabel>Opacity</ActionLabel>
  <ActionControls>

```

## Components

| Component        | Description                            |
| ---------------- | -------------------------------------- |
| `Action`         | Container with flex row layout and gap |
| `ActionLabel`    | Fixed-width label                      |
| `ActionControls` | Flex-1 control area                    |
