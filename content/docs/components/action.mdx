title: Action
description: Form field row layout for property editors.
---

## Install

```bash
npx shadcn@latest add https://substrate.vui.run/r/action
```

## Lineage

<Lineage items={[{ name: "Substrate" }]} />

## Usage

```tsx
import { Action, ActionLabel, ActionControls } from "@/registry/substrate/components/action"

<Action>
  <ActionLabel>Opacity</ActionLabel>
  <ActionControls>
    <Slider value={[50]} max={100} />
  </ActionControls>
</Action>
```

## Components

| Component | Description |
|---|---|
| `Action` | Container with flex row layout and gap |
| `ActionLabel` | Fixed-width label |
| `ActionControls` | Flex-1 control area |
