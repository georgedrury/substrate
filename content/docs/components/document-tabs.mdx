## Install

```bash
npx shadcn@latest add https://substrate.georgedrury.co.uk/r/document-tabs
```

## Components

| Component            | Description                                |
| -------------------- | ------------------------------------------ |
| `DocumentTabs`       | Root wrapper (Radix Tabs.Root)             |
| `DocumentTabList`    | Horizontal scrollable tab bar              |
| `DocumentTab`        | Individual tab with optional close button  |
| `DocumentTabContent` | Content panel displayed for the active tab |
