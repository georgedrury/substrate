## Components

| Component          | Description                                            |
| ------------------ | ------------------------------------------------------ |
| `TreeList`         | Root container with `role="tree"`                      |
| `TreeItem`         | Row with depth, selection, expand/collapse              |
| `TreeExpandButton` | Chevron toggle that rotates when expanded              |
| `TreeItemContent`  | Truncated text label                                   |
| `TreeItemIcon`     | Colour dot or icon                                     |
| `TreeItemActions`  | Right-aligned actions, visible on hover                |

## Hooks

### useTreeExpansion

Manages expand/collapse state for a set of node IDs.

```ts
const { isExpanded, toggle, expandAll, collapseAll } = useTreeExpansion(["root"])
```

| Method        | Description                          |
| ------------- | ------------------------------------ |
| `isExpanded`  | Check if a node is expanded          |
| `toggle`      | Toggle a node's expanded state       |
| `expandAll`   | Expand a list of node IDs            |
| `collapseAll` | Collapse all nodes                   |
