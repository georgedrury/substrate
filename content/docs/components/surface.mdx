## Theme variables

| Variable              | Tailwind class           | Fallback             | Description             |
| --------------------- | ------------------------ | -------------------- | ----------------------- |
| `--canvas`            | `bg-canvas`              | `--background`       | Surface background      |
| `--canvas-foreground` | `text-canvas-foreground` | `--foreground-muted` | Surface foreground/grid |

## Components

| Component         | Description                                                        |
| ----------------- | ------------------------------------------------------------------ |
| `Surface`         | Absolute-positioned container with `bg-canvas` and overflow hidden |
| `SurfaceControls` | Overlay layer with pointer-events pass-through except on children  |
| `SurfaceGrid`     | CSS radial-gradient dot pattern sized via the `size` prop          |

## Props

### Surface

Extends `React.ComponentProps<"div">`.

### SurfaceControls

| Prop       | Type                                                           | Default          | Description                        |
| ---------- | -------------------------------------------------------------- | ---------------- | ---------------------------------- |
| `position` | `"top-left" \| "top-right" \| "bottom-left" \| "bottom-right"` | `"bottom-right"` | Which corner to anchor controls to |

### SurfaceGrid

| Prop   | Type     | Default | Description                |
| ------ | -------- | ------- | -------------------------- |
| `size` | `number` | `20`    | Grid dot spacing in pixels |
