
## Usage

```tsx
import { DesignCanvas } from "@/registry/substrate/canvas/design-canvas"

export default function Editor() {
	return (
		<div className="h-screen w-screen">
			<DesignCanvas />
		</div>
	)
}
```

## Features

- HTML5 Canvas 2D rendering with `requestAnimationFrame` loop
- DPR-aware sizing for sharp rendering on retina displays
- Dirty-flag optimization — only re-renders when state changes
- Pointer event handling for create, move, resize, pan, and marquee select
- Keyboard shortcuts for tool switching, undo/redo, delete, and zoom
- Cursor changes based on active tool

## Theme variables

| Variable | Tailwind class | Fallback | Description |
|---|---|---|---|
| `--canvas` | `bg-canvas` | `--background` | Canvas background colour |
| `--canvas-foreground` | `text-canvas-foreground` | `--foreground-muted` | Grid dots and canvas UI |

Override in your `globals.css` `:root` / `.dark` blocks to theme the canvas.

## Dependencies

The canvas component pulls in the full interaction stack:

- `tool-store` — active tool state
- `use-canvas-renderer` — render loop
- `use-canvas-interaction` — pointer events
- `use-keyboard-shortcuts` — keyboard handling
