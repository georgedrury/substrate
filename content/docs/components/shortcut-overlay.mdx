## Props

| Prop           | Type                      | Default | Description                    |
| -------------- | ------------------------- | ------- | ------------------------------ |
| `groups`       | `ShortcutGroup[]`         | —       | Groups of shortcuts to display |
| `open`         | `boolean`                 | —       | Controlled open state          |
| `onOpenChange` | `(open: boolean) => void` | —       | Controlled open change handler |
| `trigger`      | `string`                  | `"?"`   | Key that toggles the overlay   |

### ShortcutGroup

```ts
type ShortcutGroup = {
	heading: string
	shortcuts: { key: string; label: string }[]
}
```

The `key` string is split on `+` and each part rendered as an individual `<kbd>`. For example `"⌘ + Z"` renders as two separate key badges.
