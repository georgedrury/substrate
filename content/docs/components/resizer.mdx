---
title: Resizer
description: Drag handle for resizing adjacent panels or panes. Visual grab dots on hover.
---

## Install

```bash
npx shadcn@latest add https://substrate.georgedrury.co.uk/r/resizer
```

## Examples

### Default

Hover over the divider to see the grab dots.

## Props

| Prop          | Type                           | Default      | Description      |
| ------------- | ------------------------------ | ------------ | ---------------- |
| `orientation` | `"horizontal"` \| `"vertical"` | `"vertical"` | Resize direction |
