## Props

Extends all native `<textarea>` props.

| Prop         | Type      | Default | Description                              |
| ------------ | --------- | ------- | ---------------------------------------- |
| `autoResize` | `boolean` | `true`  | Automatically adjusts height to content  |
| `minRows`    | `number`  | `2`     | Minimum visible rows                     |
| `maxRows`    | `number`  | `10`    | Maximum height before scrolling          |
