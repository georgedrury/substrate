## Props

| Prop            | Type      | Default | Description                                  |
| --------------- | --------- | ------- | -------------------------------------------- |
| `value`         | `number`  | —       | Current progress value                       |
| `max`           | `number`  | `100`   | Maximum value                                |
| `indeterminate` | `boolean` | —       | Show an animated indeterminate indicator      |
