## Components

| Component                | Description                                       |
| ------------------------ | ------------------------------------------------- |
| `ContextMenu`            | Root wrapper (Radix ContextMenu.Root)             |
| `ContextMenuTrigger`     | Area that responds to right-click                 |
| `ContextMenuContent`     | Popover menu panel                                |
| `ContextMenuItem`        | Clickable menu item                               |
| `ContextMenuSeparator`   | Horizontal divider                                |
| `ContextMenuLabel`       | Non-interactive section heading                   |
| `ContextMenuShortcut`    | Right-aligned keyboard shortcut hint              |
| `ContextMenuSub`         | Submenu root                                      |
| `ContextMenuSubTrigger`  | Item that opens a submenu                         |
| `ContextMenuSubContent`  | Submenu panel                                     |
