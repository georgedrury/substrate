---
title: Timeline
description: Compound timeline for keyframe animation editing with playhead, tracks, and transport controls.
---

## Install

```bash
npx shadcn@latest add https://substrate.georgedrury.co.uk/r/timeline
```

This also installs the `animation-store` dependency (Zustand).

## Components

| Component           | Description                                                                       |
| ------------------- | --------------------------------------------------------------------------------- |
| `Timeline`          | Flex-column container with panel background and top border                        |
| `TimelineRuler`     | Second-interval tick marks with time labels. Fixed label column at 128px width    |
| `TimelinePlayhead`  | Draggable vertical line with triangular handle. Updates `animation-store` on drag |
| `TimelineTrack`     | Single track row with a label column and a content area for keyframes             |
| `TimelineKeyframe`  | Diamond-shaped marker positioned by `time * zoomLevel` pixels                     |
| `TimelineTransport` | Play/pause, loop, and time display. Reads directly from `animation-store`         |

| Prop        | Type         | Default | Description                  |
| ----------- | ------------ | ------- | ---------------------------- |

No additional props. Reads state from `useAnimationStore`.

## Animation store

The timeline uses a shared Zustand store (`animation-store`) for playback state:

```tsx
import { useAnimationStore } from "@/stores/substrate/animation-store"

const { currentTime, isPlaying, togglePlayback } = useAnimationStore()
```

| Property                 | Type                                       | Description                 |
| ------------------------ | ------------------------------------------ | --------------------------- |
| `duration`               | `number`                                   | Total duration (default 5s) |
| `currentTime`            | `number`                                   | Current playhead time       |
| `isPlaying`              | `boolean`                                  | Playback state              |
| `fps`                    | `number`                                   | Frames per second (60)      |
| `zoomLevel`              | `number`                                   | Pixels per second (100)     |
| `selectedKeyframeIds`    | `Set<string>`                              | Selected keyframe IDs       |
| `setCurrentTime`         | `(time: number) => void`                   | Set time (clamped)          |
| `togglePlayback`         | `() => void`                               | Toggle play/pause           |
| `setZoomLevel`           | `(level: number) => void`                  | Set zoom (clamped 20–500)   |
| `selectKeyframe`         | `(id: string, additive?: boolean) => void` | Select keyframe             |
| `clearKeyframeSelection` | `() => void`                               | Clear selection             |
