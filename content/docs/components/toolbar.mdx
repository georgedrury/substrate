```bash
npx shadcn@latest add https://substrate.georgedrury.co.uk/r/toolbar
```

## Components

| Component            | Description                                                                   |
| -------------------- | ----------------------------------------------------------------------------- |
| `Toolbar`            | Fixed-position container with `role="toolbar"` and built-in `TooltipProvider` |
| `ToolbarToggleGroup` | Single-select toggle group (wraps Radix ToggleGroup)                          |
| `ToolbarToggle`      | Toggle button with optional tooltip and keyboard shortcut display             |
| `ToolbarSeparator`   | Vertical divider between tool groups                                          |
| `ToolbarDropdown`    | Button with dropdown menu for tool variant selection, active state highlight  |
