## Props

| Prop             | Type                             | Default | Description                              |
| ---------------- | -------------------------------- | ------- | ---------------------------------------- |
| `onAlign`        | `(action: AlignAction) => void`  | —       | Called with the alignment action          |
| `showDistribute` | `boolean`                        | `true`  | Show distribute horizontal/vertical      |
| `disabled`       | `boolean`                        | —       | Disables all buttons                     |

### AlignAction values

`left` · `center-h` · `right` · `top` · `center-v` · `bottom` · `distribute-h` · `distribute-v`
