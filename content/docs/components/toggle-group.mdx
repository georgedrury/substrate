## Props

### ToggleGroup

Extends all Radix `ToggleGroup.Root` props.

| Prop            | Type                                                 | Default        | Description                                    |
| --------------- | ---------------------------------------------------- | -------------- | ---------------------------------------------- |
| `type`          | `"single" \| "multiple"`                             | —              | Single or multi-select behaviour               |
| `value`         | `string \| string[]`                                 | —              | Controlled selected value(s)                   |
| `defaultValue`  | `string \| string[]`                                 | —              | Uncontrolled initial value(s)                  |
| `onValueChange` | `(value: string) => void \| (value: string[]) => void` | —            | Called when selection changes                  |
| `orientation`   | `"horizontal" \| "vertical"`                         | `"horizontal"` | Layout direction and arrow-key navigation axis |
| `disabled`      | `boolean`                                            | —              | Disables all items                             |

### ToggleGroupItem

Extends all Radix `ToggleGroup.Item` props.

| Prop       | Type      | Default | Description            |
| ---------- | --------- | ------- | ---------------------- |
| `value`    | `string`  | —       | Unique value of item   |
| `disabled` | `boolean` | —       | Disables this item     |
