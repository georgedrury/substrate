## Components

| Component                 | Description                                       |
| ------------------------- | ------------------------------------------------- |
| `CollapsiblePane`         | Root wrapper with Radix Collapsible state          |
| `CollapsiblePaneHeader`   | Header row with expand/collapse chevron            |
| `CollapsiblePaneLabel`    | Section title text                                 |
| `CollapsiblePaneContent`  | Animated body that collapses to zero height        |

## Props (CollapsiblePane)

| Prop           | Type                          | Default | Description                       |
| -------------- | ----------------------------- | ------- | --------------------------------- |
| `defaultOpen`  | `boolean`                     | `true`  | Initial open state (uncontrolled) |
| `open`         | `boolean`                     | —       | Controlled open state             |
| `onOpenChange` | `(open: boolean) => void`     | —       | Called when open state changes     |
