## Components

| Component        | Description                        |
| ---------------- | ---------------------------------- |
| `Popover`        | Root wrapper (Radix Popover.Root)  |
| `PopoverTrigger` | Element that opens the popover     |
| `PopoverContent` | Floating panel with optional arrow |
| `PopoverClose`   | Positioned close button            |

## Props (PopoverContent)

| Prop         | Type      | Default | Description                     |
| ------------ | --------- | ------- | ------------------------------- |
| `showArrow`  | `boolean` | —       | Show a directional arrow        |
| `sideOffset` | `number`  | `6`     | Gap between trigger and popover |
