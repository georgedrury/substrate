---
title: Controls
description: Config-driven control panels – describe parameters as an object and render them with Substrate controls.
---

Describe a panel as a plain object and get typed values back. `Controls` renders every registered panel with Substrate's own components, so it sits inside a `Panel` like any hand-built pane.

The config format and store come from [DialKit](https://github.com/joshpuckett/dialkit) by Josh Puckett (MIT). Substrate uses its headless store and supplies the interface.

## Install

```bash
npx shadcn@latest add https://substrate.georgedrury.co.uk/r/controls
```

## Usage

```tsx
import { Panel } from "@/components/substrate/panel"
import { Controls } from "@/components/substrate/controls"
import { useControls } from "@/hooks/substrate/use-controls"

function Editor() {
  const card = useControls("Card", {
    radius: [16, 0, 48],
    colour: "#a78bfa",
    visible: true,
    shadow: { blur: [24, 0, 64] },
  })

  return (
    <>
      <div style={{ borderRadius: card.radius, background: card.colour }} />
      <Panel>
        <Controls />
      </Panel>
    </>
  )
}
```

Keys become labels, and the returned values keep the same nesting as the config.

## Config

| Control | Definition | Returned value | Rendered with |
| --- | --- | --- | --- |
| Slider | `radius: [16, 0, 48]` | `number` | NumberSlider |
| Slider with step | `radius: [16, 0, 48, 2]` | `number` | NumberSlider |
| Inferred slider | `scale: 1.2` | `number` | NumberSlider |
| Toggle | `visible: true` | `boolean` | Toggle |
| Text | `title: "Hello"` | `string` | TextArea |
| Colour | `colour: "#a78bfa"` | `string` | ColourPicker |
| Select | `align: { type: "select", options: ["left", "right"] }` | `string` | Select |
| Easing | `motion: { type: "easing", duration: 0.3, ease: [0.25, 0.1, 0.25, 1] }` | `{ type, duration, ease }` | EasingCurveEditor |
| Spring (time) | `motion: { type: "spring", visualDuration: 0.3, bounce: 0.2 }` | `{ type, visualDuration, bounce }` | SpringEditor |
| Spring (physics) | `motion: { type: "spring", stiffness: 200, damping: 25, mass: 1 }` | `{ type, stiffness, damping, mass }` | SpringEditor |
| Image | `cover: { type: "image", options: ["/a.jpg", "/b.jpg"] }` | `string` (URL or data URL) | ImagePicker |
| XY pad | `offset: { type: "pad", x: [0, -50, 50, 1], y: [0, -50, 50, 1] }` | `{ x, y }` | XYPad |
| Action | `replay: { type: "action" }` | Calls `onAction("replay")` | Button |
| Folder | `shadow: { blur: [24, 0, 64] }` | Nested values | CollapsiblePane |

Slider tuples are `[default, min, max, step?]`. Add `_collapsed: true` inside a folder to start it closed.

Easing and spring controls share one row with an Easing / Time / Physics switch, as in DialKit. Switching changes the shape of the returned value, and switching back restores the previous settings. Uploaded images are stored as data URLs, so prefer `options` for large images when persisting values.

## useControls

```ts
const values = useControls(name, config, options)
```

| Option | Type | Description |
| --- | --- | --- |
| `id` | `string` | Keeps values across unmounts and shares them between mounts using the same id |
| `persist` | `boolean \| { key?, storage?, presets? }` | Saves values to browser storage |
| `onAction` | `(path: string) => void` | Called with the path of a clicked action control |
| `shortcuts` | `Record<string, ShortcutConfig>` | Keyboard shortcuts for sliders and toggles, by control path |

### Shortcuts

```tsx
const card = useControls("Card", {
  radius: [16, 0, 48],
  shadow: { blur: [24, 0, 64] },
  visible: true,
}, {
  shortcuts: {
    radius: { key: "r", mode: "fine" },
    "shadow.blur": { key: "b", interaction: "drag" },
    visible: { key: "v" },
  },
})
```

Hold **R** and scroll to adjust the radius, hold **B** and drag to adjust the blur, and press **V** to toggle visibility. Holding a slider's key also lets the arrow keys step it. The row being adjusted is highlighted, and each row shows its key next to the label.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | The key to hold or press |
| `modifier` | `"alt" \| "shift" \| "meta"` | — | A modifier that must also be held |
| `interaction` | `"scroll" \| "drag" \| "move" \| "scroll-only"` | `"scroll"` | How a held slider key adjusts the value. `"scroll-only"` needs no key and claims every scroll, so use it sparingly. |
| `mode` | `"fine" \| "normal" \| "coarse"` | `"normal"` | Step size: 1% of the range, the slider's step, or 10% of the range |

Shortcuts pause while a text field, select or menu has focus, so typing is never captured.

### Setting values from code

`useControlsController` registers the same panel and also returns setters, for loading a saved state or applying a preset:

```tsx
const parameters = useControlsController("Parameters", {
  steps: [30, 1, 100, 1],
  cfgScale: [7, 1, 20, 0.5],
})

parameters.values.steps
parameters.setValues({ steps: 40 })
parameters.reset()
```

### Values that belong to a selection

A panel owns its values, which suits settings with local state. When the values belong to something selectable, mount a small component per selection with `key`, seed the config from the selected item, and write edits back:

```tsx
function MaterialControls({ object, onChange }: Props) {
  const [config] = useState(
    () =>
      ({
        colour: object.colour,
        roughness: [object.roughness, 0, 1, 0.01],
      }) satisfies ControlsConfig,
  )
  const material = useControls("Material", config)

  const onChangeRef = useRef(onChange)
  onChangeRef.current = onChange
  useEffect(() => {
    onChangeRef.current(material)
  }, [material])

  return <Controls panel="Material" />
}

<MaterialControls key={selected.id} object={selected} onChange={update} />
```

This works when nothing else edits those values while the item is selected. If they also change elsewhere (dragging on a canvas, undo), compose the individual controls by hand so they read straight from your store.

## Controls

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `panel` | `string` | — | Render only the panel with this name or id. Renders every panel when omitted. |

Each panel header has three actions:

- **Versions** switches between versions of the panel's values. Edits apply to the version you are on, and **New version** starts a copy of the current values. Version 1 is the values before any version was made. Versions last for the session, or are saved with the values when `persist` is set with `presets: true`.
- **Copy values** copies the current values as an instruction for an agent to make them the new defaults in the `useControls` call.
- **Reset** restores the config defaults.
