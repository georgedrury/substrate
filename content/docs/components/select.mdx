## Components

| Component         | Description                                |
| ----------------- | ------------------------------------------ |
| `Select`          | Root wrapper (Radix Select.Root)           |
| `SelectTrigger`   | Button that opens the dropdown             |
| `SelectValue`     | Displays the currently selected value      |
| `SelectContent`   | Dropdown panel with items                  |
| `SelectItem`      | Selectable option with check indicator     |
| `SelectGroup`     | Labelled group of items                    |
| `SelectLabel`     | Non-interactive group heading              |
| `SelectSeparator` | Horizontal divider                         |
