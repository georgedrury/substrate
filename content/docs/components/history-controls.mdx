## Components

| Component         | Description                                                   |
| ----------------- | ------------------------------------------------------------- |
| `HistoryControls` | Inline flex container with undo and redo buttons               |
| `HistoryButton`   | Individual icon button with disabled state styling             |

## Props

### HistoryControls

| Prop   | Type             | Default | Description       |
| ------ | ---------------- | ------- | ----------------- |
| `size` | `"sm" \| "md"`   | `"md"`  | Button and icon size |

Extends `React.ComponentProps<"div">`.

## Behaviour

The component reads directly from the document store:

- **Undo** is enabled when `past.length > 0`
- **Redo** is enabled when `future.length > 0`
- Disabled buttons drop to 30% opacity and ignore pointer events

Keyboard shortcuts (`Cmd+Z` / `Cmd+Shift+Z`) are handled separately in `use-keyboard-shortcuts` — this component only provides the visual controls.
