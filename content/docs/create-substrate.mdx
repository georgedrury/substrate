## Quick start

```bash
npx create-substrate
```

The CLI walks you through three choices — project name, surface type, and package manager — then scaffolds a working Vite + React project with the right components, stores, and skills pre-installed.

```bash
npx create-substrate my-editor --surface canvas-2d --pm pnpm
```

Pass flags to skip the prompts entirely.

## Surface types

Each surface type installs a meaningful starter page — not just the right imports, but something you can interact with immediately.

### 2D canvas

The default surface. A full spatial design tool with canvas rendering, hit testing, and element manipulation.

| Detail | Description |
| --- | --- |
| Starter page | Toolbar with shape and selection tools, left panel with a layer list, right panel with transform and fill properties |
| Components | design-canvas, toolbar, panel, pane, layer-list, number-input, colour-picker, history-controls, status-bar, zoom-controls |
| Stores | document-store, tool-store |

### 3D scene

An interactive Three.js viewport with orbit controls and selectable objects.

| Detail | Description |
| --- | --- |
| Starter page | A scene with sample meshes (box, sphere) on a grid, toolbar with select, move, rotate and scale modes plus add and delete, right panel with an object list, lighting, transform and material properties |
| Components | toolbar, panel, pane, controls, number-input, status-bar |
| Extra dependencies | three, @react-three/fiber, @react-three/drei |

### Animation

A timeline-based motion editor with keyframe editing and playback.

| Detail | Description |
| --- | --- |
| Starter page | Split layout with a preview stage and timeline below, sample keyframes on two tracks (position, opacity), transport controls in the timeline, right panel with an easing curve editor and playback inputs |
| Components | panel, pane, timeline, easing-curve-editor, number-input, status-bar |
| Extra dependencies | gsap |
| Stores | animation-store |

### Node editor

A visual programming canvas with typed ports and SVG wire connections.

| Detail | Description |
| --- | --- |
| Starter page | Pannable, zoomable surface with a live-evaluated sample graph (number, colour, add, mix and output nodes) connected by typed wires, toolbar for adding nodes, right panel with node properties |
| Components | toolbar, panel, pane, node, number-input, colour-picker, status-bar, zoom-controls |

### Data vis

An interactive chart explorer with configurable visualisations.

| Detail | Description |
| --- | --- |
| Starter page | Chart surface rendering a sample dataset as a line, area or bar chart, left panel with metric and range controls, right panel with chart styling. Both panels are generated from config with `useControls` |
| Components | toolbar, panel, controls, status-bar |
| Extra dependencies | recharts |

### Image generation

A prompt-driven image creation tool with gallery history.

| Detail | Description |
| --- | --- |
| Starter page | Central preview of the selected image, left panel with prompt input, seed, steps and CFG controls, right panel with a gallery of generation history. Generation is mocked locally; wire in your own model call |
| Components | toolbar, panel, pane, action, controls, gallery, text-area, number-input, progress-bar, status-bar, empty-state |

### Blank

Just the scaffold shell — bring your own surface.

| Detail | Description |
| --- | --- |
| Starter page | Toolbar, two empty panels, and a Surface component in the middle with a centred empty state |
| Components | toolbar, panel, pane, surface, empty-state, status-bar |

## What gets generated

Every surface produces the same project structure with surface-specific content where it matters:

| File | Notes |
| --- | --- |
| `package.json` | Dependencies vary by surface type |
| `index.html` | Vite entry point with dark theme |
| `src/globals.css` | Base tokens plus surface-specific CSS variables |
| `src/main.tsx` | React mount |
| `src/App.tsx` | Surface-specific starter page |
| `src/lib/utils.ts` | `cn()` utility |
| `vite.config.ts` | Vite with React and Tailwind plugins, `@/` alias |
| `components.json` | Registry config |
| `CLAUDE.md` | Substrate context and skill index |
| `.claude/skills/` | All 17 skills (surface guides and domain references) |
| `.mcp.json` | Substrate MCP server |
| `tsconfig.json`, `tsconfig.app.json` | TypeScript config |

## CLI reference

```bash
npx create-substrate [project-name] [options]
```

| Flag | Description |
| --- | --- |
| `--surface <type>` | Surface type: `canvas-2d`, `3d-scene`, `animation`, `node-editor`, `data-vis`, `image-gen`, `blank` |
| `--pm <manager>` | Package manager: `npm`, `pnpm`, `bun` |
| `--skip-install` | Skip dependency installation |
| `--skip-git` | Don't initialise a git repository |

If you already have a project and want to add Substrate to it, use `npx @substrate-kit/cli init` instead — it installs skills, CLAUDE.md, and configuration without creating a new directory.
