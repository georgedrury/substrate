## Surface skills

Skills that teach Claude how to set up and wire different types of creative surfaces into the Substrate chrome.

</Skills>

Substrate's default surface. Covers the full rendering pipeline, coordinate systems, element CRUD, hit-testing, and how to extend with custom element types and rendering logic.
